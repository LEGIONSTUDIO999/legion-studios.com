LEGION STUDIOS WEBSITE
======================

1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.
3. Use the GAMES section to launch playable builds.
4. Use the MUSIC section to play the four MP3 tracks bundled in assets/music.

The ProcessingJS-based game builds load Processing.js from cdnjs, so an internet connection is needed for those games.
The audio files are local to this package and do not need to be re-uploaded.

Contact: legionstudios.dev@outlook.com

Playable builds included:
- Infinite Platform Dash
- Need for Speed: Reborn
- Resident Evil: Endless Survival
- Pac-Man: Reloaded
- Retro 2D Mini-Game
- Glitch Pong
- Dino Spanish Run

Mars Shuttle Run and Dino Dash are listed as in development because their standalone playable builds were not available in the project files used for this package.
